# 云山：精细体素美术，先概念图后图生模型

2026-10-02 用户最新要求，优先于此前 Tripo 文生3D首批提示词。云山继续在当前云端工作区开发；grok仅承接用户电脑操作、素材生成与原文件交付，不迁移或替换游戏仓库，不重建脚手架。

## 必须采用的顺序

1. 读取用户 GitHub 参考原图与《提示词.md》及当前实际游戏截图，提取精细体素城市的造型语言。
2. 用参考图和文字生成**聚焦单件资产的体素概念图**。A1先只画一件开敞木门框，不画整座建筑、城市或一组道具。
3. 实际看概念图，核对体素轮廓、开洞、柱梁厚度、比例、细节和与现有城市的统一性。图不成立先修图，不直接提交模型。
4. 概念图成立后，在Tripo采用**图生模型**，携带相同尺寸、开洞、体素、面数与材料约束。后续不继续直接文生3D。
5. 导出原GLB/贴图，记录任务链接。游戏开发者实检三维几何与纹理、必要的体素转换/LOD、碰撞净空，再在真实可玩市集接入。Tripo预览、漂亮概念图均不能代替游戏内验收。

此流程不额外授权购买或升级。使用现有额度也由电脑操作消费者记录实际消耗，不批量自动重抽。

## 体素造型规范

| 项目 | A1可执行约束 |
|---|---|
| 基本风格 | 精细离散体素建筑部件；清楚方块阶差、直角木构、平面色块。参考城市的细节和层次进入体素结构，而非变成光滑写实建筑 |
| 细节格 | 资产局部采用0.05m网格；外框72×60×6格。与现有0.2m世界尺度兼容，不改世界体素尺寸、楼体或身体规则 |
| 外框与开洞 | 外宽3.6m、高3.0m、深0.30m；贯穿净洞3.2×2.8m（64×56格）。柱与上梁厚0.20m（4格），无底槛、门扇、玻璃、背景板或墙体填洞 |
| 表面 | 硬边、平面法线、克制像素色差；木纹表达可采用体素面内像素，不使用强摄影级纹理、曲面倒角、细密圆滑雕花或整件模糊贴图 |
| 木构细节 | 榫接、短梁端和简单几何纹样采用离散格块与阶梯缺口；不以随机碎块、破损噪声或巨大方条代替细节 |
| 配色 | 去饱和深褐木，少量旧朱褐，淡灰石柱脚。材质边界明确，既不能一整块纯棕，也不能变成写实金漆宫殿 |
| 光照 | 概念图可用柔和中性光看形；模型颜色图不烘固定光影。动态日夜、实际供电与有限灯光仍由游戏实现 |
| 拓扑和预算 | GLB实际近景≤2500三角形。体素不意味着逐格输出所有六面；应删除内部面、合并相容共面/同材质表面，保持离散轮廓。中景目标≤700，远景省略装饰而保原主体 |
| 坐标和材料 | Y向上、正面+Z、底面中心枢轴；完整UV、非金属木/石PBR，1K目标贴图。网页最低2K时保原件，记录真实尺寸，后续再优化，不假称已1K |

门洞检查不能只看一条中心射线：需检查整个人体通路与贯穿洞体积。材质透明不能掩盖实际填洞三角形。未满足尺寸时先记录原bounds与比例，不能任意非均匀拉伸后声称合格。

## A1单件概念图提示词

以下先交给grok电脑上的图像生成工具，**不是直接粘贴到Tripo文生3D**。可以使用两张原城参考图作为风格参考；输出仅一件资产。

```text
根据所附云山中式山城参考图和项目“第一人称精细体素城市生活”的文字要求，生成一张供后续图生3D使用的单件资产概念图：开敞的中式市集木门框。必须是精细体素风格，所有实体由清楚的离散小方块和直角阶差组织，硬边、平面面片、克制像素色块；不要平滑写实木雕、圆角CG建模、摄影级木纹或灰色白模。

门框外廓宽3.6米、高3.0米、深0.30米，比例严格为72×60×6个5厘米体素。左右柱和上梁各厚20厘米（4格）。中央保留贯穿净宽3.2米、净高2.8米的完整空洞：透过洞看到与周围完全相同的中性背景。没有底梁、门槛、门扇、玻璃、门洞背景板或墙。柱脚淡灰石块只在柱范围内，不伸进通路。

去饱和深褐木、少量旧朱褐、克制像素木纹；榫接、梁端和简单几何花纹通过细小体素阶差可读，结构精致但不碎乱，不是三根粗大方条。单一门框居中、正交近正面三分之四视图，稍露一侧和梁底以看清真实厚度；整件完整入镜。纯浅灰背景，中性柔光，无地面、底座、投影黑块、场景、城市、屋顶、人、文字、尺寸标注或多视图拼贴。画面清楚、可据此判断洞口和体素结构，只有这一件门框。
```

概念图实际核对：门洞贯穿、框比例1.2:1、柱梁约1/18外宽与1/15外高、厚度可辨；近看有统一细格和榫接，远看清楚木构轮廓。根游戏会话或grok消费者实际看图后才能判断，不用文字描述冒充看过。

## 概念图通过后的Tripo图生补充文本

选择图生模型，输入上一步实际核对后的原图；保留原图作为资源来源，不把整城参考图直接当目标物体。

```text
Reconstruct ONLY the approved fine-voxel Chinese market doorframe from this image. Preserve discrete 5 cm grid blocks, stepped details, hard edges and flat faces; no smooth realism, round bevels or curved carving. Outer size 3.6 x 3.0 x 0.30 metres. The central passage must be fully open through the model, 3.2 m wide and 2.8 m high. No door, wall, glass, threshold, background plane, ground or pedestal. Dark muted walnut with small aged vermilion accents and pale stone feet contained under the posts. Y-up, front +Z, bottom-centre pivot. Model the back and underside. Clean UVs and non-metallic PBR timber/stone; no baked lighting. Remove internal voxel faces and merge compatible coplanar faces without smoothing the voxel silhouette. Target <=2500 actual triangulated faces. Export original textured GLB. Match the approved image rather than inventing another architectural style.
```

此补充文本小于网页1000字符上限，最终面数仍由原GLB实测，网页档位不能代替验收。图生若仍输出圆滑模型，也不能直接宣称符合体素风格。
