实际为612栋、11片区、674交通节点、691边。商铺109+银行32共141栋，最高商业楼66米/15层；按本图审阅阈值（高层>=80米或20层、摩天>=150米）两项均为0。234米/30层的天枢阁是政治/能源中枢，不能算商业CBD。住宅221栋；完整用途统计见原JSON。

地图保留50米实际terrainHeight网格、等高线、真实旋转首层room/gallery/wall投影和庭院留白，标出道路、桥、磁悬浮、轻轨、缆索、升降、渡轮和航线，以及河流、瀑布和机场跑道。坐标为本地XZ米制；-Z向上不是地理北。虚线圈是设计半径，不是行政边界；线宽为图示，不代表实际道路宽度。地形采样包含实际地面/地下凹陷；静态地图不证明真实路线通达、经济稳态或渲染美术验收。

原World只生成一次，102输入首尾SHA一致。08到09仅计时/休息兼容和测试变动，地图涉及的世界、平面、权限与fingerprint四个源逐字相同。此Git目录是可直接查看的原件子集；完整细件GeoJSON、footprints与地形二进制在生产者原数据包中，不能把158877细件当作楼栋数量。`collect-city-map.mjs`、`plot-city-map.py`是实际运行脚本原件；重新绘图需完整数据包里的输入，不能只用此子集假称复现。

Library唯一一次有序4件保存在tools/list网络失败，尚未prepare、上传或finalize，真实Library ID为0；失败回执保留。此目录是已获授权工作分支的Git备份，不是已送达的Library附件。完整原数据见[原始数据ZIP](云山巨城-当前城市地图-原始数据.zip)，25成员原字节/CRC/逐SHA均核验通过。
