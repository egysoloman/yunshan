## 这座城现在是什么规模

实际共有 **612 栋建筑、11 个城区、674 个交通节点和 691 条交通边**。住宅 221 栋、市集 109 栋、银行 32 栋；其他用途见 `city-census.json` 与 `buildings.csv`。

本报告把原生 kind 为 `market` 或 `bank` 的建筑计为商业用途，共 **141 栋**。商业楼最高 **66 米、15 层**。按本图明确采用的审阅阈值——商业楼体高度至少 80 米或层数至少 20 层——商业高层为 **0**；按商业楼体至少 150 米的摩天楼阈值，摩天楼为 **0**。这些是本图的统计规则，不是法律分类，也不把住宅、官署或主阁算作商务楼。

天枢阁 `core-main` 为 **234 米、30 层**，是市政／能源地标。星港 `starport-b0` 为 **92.4 米、14 层**。高度来自 `Building.height`，是楼体高度，不是地面海拔加楼高，也不额外计屋顶装饰。现有 World 没有独立办公塔楼 kind；本地图无法证明真实商店营业或居民生活状态。静态 World 不含 NPC 实际人数，图中不以动态人数充当静态统计。

交通边按原生 mode 分为道路 671、桥 4、磁悬浮 4、轻轨 5、缆索 2、升降 1、渡船 2、航线 2。机场跑道是实际道路边 `road-airport-runway-strip`，长度 960 米；它包含于道路 671 条。瀑布原生顶点 Y=256 米、底点 Y=103 米，落差 153 米，宽 24 米；不要把地图上的线长当作垂直落差。

## 坐标、地形与轮廓的准确范围

地图采用游戏本地 X／Z 坐标，单位为米；上方为 **−Z**，下方为 **+Z**。世界没有给出真实地理北向或经纬度，所以图中箭头不是地理北。GeoJSON 也使用本地坐标，不是 WGS84：其三维坐标顺序为 `[x, z, y]`。

世界名义宽度 4400 米，绘图范围为 X／Z 各 −2300 至 2300 米。地形采用原生 `terrainHeight(world,x,z)`，每 **50 米**采样一次，共 93 × 93 = **8649 点**；默认包含地下开挖影响。等高距 50 米，样本海拔范围约 2 至 614.84 米。地形显示是采样底图，不能代表 0.2 米体素精度或步行／坡台安全验收。

建筑轮廓来自真实 **首层房间、廊道及墙带投影**，不是整栋外包 AABB，也不是屋顶／全部楼层投影。院落透明保留底图。605 栋使用 current-v4 provider，7 栋保留原生旧几何；612 栋当前原生 rotation 均为 0。生成器经过原生坐标变换，但这批数据不构成非零旋转回归。

`city-layers.geojson` 的 158877 个 feature 不是楼数。它包含 152469 个首层几何投影（房间 3451、廊道 1881、墙带 133634、玻璃 13496、旧轮廓 7）以及院落、道路、城区和其他图层。多层墙带在平面上可以重叠。绘图使用同色不透明栅格，避免重复投影颜色叠加造成假高度。极小或退化投影没有绘成面，原始描述仍保留；本次没有修复或宣称所有窗几何合格。
