五楼共 137 个真实楼层。图上 1F 对应代码 floor=0 的原钱庄公共柜台与接待，2F 为金融咨询与办事厅，3F 起为结算、业务、账务复核、档案协作办公室，顶层为上层办公与城市会客厅。全层程序与权限保留在原 World JSON 和建筑 CSV 中。这里不新增公司、产权或岗位资格；这些楼仍是原银行，五楼不等于完整 CBD。

11 个原城区为：清溪水岸、千灯市集、青铜工坊、松风里、文澜学苑、玉衡官署、瀑云天枢、九霄观云、临岚坊、南岫空港、云外星港；各区建筑与初始 NPC 数见 `districts.csv`。

地形来自 `terrainHeight(world,x,z,false)` 的 **40 m 网格**，包含实际地质高差、地基与道路整平，不含地下室凹陷。等高线间隔 40 m；显示插值不增加采样精度。建筑来自共享首层室内、回廊及真实墙体投影，按原建筑旋转转换，保留开放庭院。另保留实际 slab 支持边界和孔洞原数据。天枢主阁及六座亭阁没有共享 FloorPlan，图中明确用原尺寸的旋转包络回退；没有把其主体高度冒称已测实际屋顶峰。

坐标是游戏本地 X/Z 米制，−Z 在上，不是经纬度或地理北。虚线圈是原设计半径，不是行政或土地权属边界。道路直接绘制实际 `edge.points`；跑道为实际 `road-airport-runway-strip`，960×44 m。静态线条不证明全线通达，初始 NPC 数不证明自然到岗、人口稳定或经济稳态；本图没有 GPU、浏览器、正常 W 旅程、美术或性能验收。

采集窗口约 10.8 秒，60 份源码与配置的 `source-start.json` / `source-end.json` 字节 SHA 完全一致，所有查询与初始构造前后的原 World JSON 完全一致。`source-bound/` 保存这 60 份实际原字节，未编辑共享源码。初始 `source-before.json` 为任务开始前的预读记录；真正绑定本图的是采集窗口的 start/end。根代理后续工作不被这份源快照替代。

原首层投影收集曾有 233 个 `invalid region` 回退，实因墙体投影中的 590 条零面积矩形。原收集数据与日志完整保留；后续 `project-footprints.mjs` 仅在派生 2D 输入中去除零面积，重新使用共享 union 边界，剩余警告为 0，原世界、墙、碰撞与源代码均未修改。该投影输入修正不称为生产几何修复。

复绘命令：在本目录安装/具备 Python 的 matplotlib、numpy、Pillow 后，运行 `python3 plot-city-map.py`。使用原 World JSON 和源码快照重算首层绘图轮廓的命令为 `node --import tsx project-footprints.mjs`，需本地提供项目依赖。`collect-city-map.mjs` 是本次实际执行的采集脚本，原绝对 shared 路径保留，禁止直接覆盖已有导出；若重新采集，应使用新目录和明确的新源版本。
