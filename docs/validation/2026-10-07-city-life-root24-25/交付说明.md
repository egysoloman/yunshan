# 云山巨城：2026-10-07 阶段交付

普通新游戏已从实际公共街道出生。新版曲檐、路面和护栏开口共用渲染与碰撞几何；导航通向实际店门，玩家能够步行、E 进店、走到柜台购物、返回并 E 出店。已有存档继续使用自己的布局。

完整浏览器验收实际通过 39 个原生操作及 6 张原始截图；之后仅修改普通新游戏的布局选择，重新构建并通过普通入口限定检查。完整交互来自 build01，普通入口来自 build02，两者之间只有 main.ts 的新游戏布局选择不同。Linux 软件 GPU 验证功能与图像，macOS 硬件性能仍未验证。

跨日经济审计完成了 344 个完整窗口加 16 个冷续档窗口，共 360 个自然时间窗口、两个冷段。实际结算 438 笔工资、12,030.1791 云币。原失败窗口仍保留，不补造缺失阶段；居民低饱足增加、缺货店与行程问题仍需继续追踪，不能宣称长期稳态。

参考图的城区层次、地形与建筑衔接、街景、光影和室内家具仍有明显缺口，完整需求 38 个域都保持 PARTIAL。能源、医疗、科技、教育、政治、环境卫生、疾病、灾害、商业更替、居民意愿与改造等既有实现和剩余闭环详见需求矩阵及接续记录。

## 运行与操作

从仓库运行 `npm ci`、`npm run dev`，打开终端显示的本地地址。生产构建使用 `npm run build`、`npm run preview`。独立源码包 `ROOT25-SOURCE-FINAL-41703.zip` 解压后同样可运行这些命令。

WASD 步行，鼠标拖动环顾，E 进入或退出建筑。购物须走到柜台附近；城市手册提供导航、身份、治理、画面设置及保存、导入和导出。无人机与飞机沿城内设施获取和登机规则使用。macOS 的实际帧率、Safari/Firefox 硬件兼容性仍需要实机验收。
