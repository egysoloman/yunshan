## 结论与合同

固定半径 `r=.35`、高度 `H=1.72` 的直立圆柱沿 `P(t)=A+t(Z-A), t∈[0,1]` 连续移动。对固定、有限、有序的局部轴对齐 Rect Box，应判定**同一时刻**是否同时满足严格竖直重叠与水平距离条件；整腿最大脚高不能代替逐时刻脚高。

父任务已明确：新 helper 默认真实几何 `footAllowance=0`，可显式传入 `.01/.22` 做原政策对照，不自动选择。纯几何竖直条件是 `bottom-H < feet(t) < top`。原 floor movement 的可踏过政策 `s=steppable?.22:.01` 则是 `bottom-H < feet(t) < top-s`。`s` 不是 epsilon；此审查对两者均成立。

保留原水平边界时，使用 `q=r*r-1e-7` 和严格 `distanceSquared < q`。对固定 `.35`，`q>0`，原闭矩形中心线相交的提前返回也满足该严格距离条件，故可统一为最小距离判定。epsilon 作用于**距离平方**；不能改成 `distance < r-eps`、扩张矩形方角或 `<=q`。

## 先裁剪竖直时间

令 `L=bottom-H`、`U=top-s`、`dy=Z.y-A.y`。先拒绝 `L>=U`。

- `dy===0`：直接检查 `L<A.y && A.y<U`；成立则有效时间为整个 `[0,1]`，否则为空。
- `dy!==0`：令 `t0=(L-A.y)/dy`、`t1=(U-A.y)/dy`，取 `lo=max(0,min(t0,t1))`、`hi=min(1,max(t0,t1))`；只有 `lo<hi` 才有有效时间。不要用任意小速度阈值、时间 epsilon 或 `lo<=hi`。

真实竖直可行集的一端或两端可能开放；它在非空时稠密于闭包 `[lo,hi]`。水平距离连续，所以闭包最小值 `<q` 时，即使最小点在开放端点，也必存在邻近的真实可行时刻满足 `<q`；最小值 `==q` 则不存在。因而直接在闭包求最小距离，再严格比较，数学上精确，无需 `nextafter` 或把开端点向内移动。

## 精确水平算法：裁剪后的线段到矩形距离

令 `C0=P(lo).xz`、`C1=P(hi).xz`，在该线段上求与闭 Rect 的全局最小距离平方。

1. 先用闭 slab 区间求 `C0→C1` 是否与 Rect 相交；相交则最小距离为零。每轴的零位移判断使用 `change===0`；若静止坐标在轴界外则拒绝，否则不限制时间。非零位移按两个轴界交点裁剪 `[0,1]`。边界相交保留。
2. 不相交时，最小距离是两端点到 Rect 的距离与四个 Rect 角点到线段的距离，共六项的最小值。端点距离使用 `max(x0-x,0,x-x1)^2 + max(z0-z,0,z-z1)^2`；角点投影参数夹到 `[0,1]`，零长度线段直接取点距。
3. 只返回 `minimumSquared < q`。

这构成 Rect 与圆盘的真实 Minkowski rounded rectangle 判定，包含边带与圆角，常数工作量。理由：不相交的两个线段若最近点都在内部，则它们平行，最短距离也可由某一段端点取得；所以扫描圆柱中心线端点及矩形四角足够。不能仅检查扩大后的 AABB，后者在四角会产生假碰撞。

另一种等价实现是按 `x/z` 穿越四个矩形轴界的时间切分 `[lo,hi]`；每段的 `point→Rect` 距离平方为凸二次式，检查段端点与区间内二次顶点即可。它同样连续精确，但实现较长；若选用它，切分点仅合并真正相等值，候选处重新用原 point→Rect 表达式计算距离，避免展开二次式的抵消误差。

## 通用 `r=0` 必须单独处理

本节是可选的通用合同建议；实际新helper为固定正半径身体接口，明确拒绝 `r<=sqrt(eps)`，不声称支持零半径。若未来另扩支持 `r=0` 的原闭 Rect 接触语义，`q<=0` 时原外侧 `distanceSquared<q` 永远不成立，但原中心线与闭 Rect 相交仍阻挡；不能统一成 `minimumSquared<q`。若保留原合同，`0<r<=sqrt(eps)` 也具有这个相同的闭 Rect 核心边界。

此分支应求原整个线性 XZ 轨迹在 Rect 内的**闭时间区间** `J`，再与竖直真实严格可行集求交：交集正长度则阻挡；交集只有一个时刻，则只有该时刻属于竖直真实可行集才阻挡。竖直根端点均排除，裁到 `t=0/1` 的端点只有原始严格高度条件成立才包含；可保存这些包含标志。不要仅把竖直闭包裁成线段后使用闭相交返回 true。

因此，在竖直有效时间内部恰好触碰 Rect 角点的零半径轨迹阻挡；仅在 `head==bottom` 或 `feet+s==top` 的被排除端点触角不阻挡。固定 `.35` 的 `q>0` 分支仍可使用前述闭包最小距离证明。

## 边界与浮点建议

- 全静止、仅竖直移动、仅水平移动均自然退化；水平零长度不能除以零。矩形零宽/零深也可按闭集合处理。有限有序的边界应是明确输入合同，异常输入不能静默变成“路线安全”。
- 顶面等于 `feet+s`、底面等于 `head` 以及水平距离平方等于 `q`，均不阻挡；有效竖直时间缩成一点也不阻挡。保持这些严格条件，不另加接触容差。
- 不把任意小的非零 `dy/dx/dz` 当成静止。原 `segmentIntersectsRect` 的 `abs(change)<eps` 不应搬进新的精确原语。有限输入不保证平方/差值永不溢出；当前城市米制范围不会逼近双精度上下界，但通用 helper 应说明或检查派生值范围。
- 先在同一固定 building-local frame 中变换两个端点。`buildingLocalPosition` 的平移加固定 yaw 保持轨迹线性与圆盘距离；圆柱不需要额外朝向。pitch/roll、随时间转动的 box 或变换缩放不在此证明内。
- 严格阈值附近仍有普通 IEEE-754 舍入限制；不要用新的 epsilon 掩盖它或声称跨坐标变换 bitwise 相等。固定 `.35` 下，原 `q` 已略小于真实半径平方；不要把几何切触改成阻挡。
- 原 sampled `blocksRoofMovement` 及 gable 高度并不是固定 Rect Box 连续几何；本算法证明不自动覆盖它们。
