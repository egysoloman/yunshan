# 默认 14 日食品与物料因果观察

这是当前食物/工业物料分型代码的隔离 **14 日实际运行**，不是新 30/60 日结果，也不是经济稳态证明。隔离目录 `/tmp/yunshan-food-material-default14-20261001` 来自根代理已冻结的 `/tmp/yunshan-phase2-root-coherent-01`。未改共享生产代码，也未注入资金、库存、需求、移动速度、工作出勤或路线。观察器只读同一个 `Simulation`，金融/生命/科研守卫保留原样。

输入 seed=20261001，税率 8%，警务预算 30%，speed=8，10,080 Tick，20,160 实际游戏分钟。金融审计命令使用隔离 `scripts/economy-audit.ts`，附加只读观察器和最终原始存档导出；具体差异见 [isolated-observer.patch](isolated-observer.patch)。

原审计 `status=passed`、进程 exit=0，616 NPC 存活、0 NPC 死亡；无人照料玩家死亡另列。居民钱包合计增加 16.0026%，公库 80,000 → **11,292.4686**，平均饥饿需求值 30.7403、平均健康 86.5125，319 人饥饿值低于 20，其中 **287 人钱包至少 15**。现金残差 −3.6962e−8，公共收支残差 −4.0240e−8。保留守卫通过与严重生活/财政缺口这两个事实，不能用存活或现金增长替代稳态结论。

`snapshot-manifest.json`、观察器和其最终检查覆盖 **30 个 src 文件**，copy/start/end SHA-256 一致；原金融 audit 自带 **13 个源文件** start/end SHA-256 一致。30 是本次真实扫描数量；此前根代理整套复制的 81 文件 scope 不应混称本审计的 hash 数量。最终存档读写逐字节一致，逐 NPC 路网查询与设施选择前后 `exportSave()` 逐字节不变。

货运原件显示 **60/60** 生成时载货的历史货车/航班最终都是空载。之前“59”的口头数字更正为 60。核心 `traffic()` 原装货代码被嵌在 `if (vehicle.cargo > 0)` 内，空货车不能再装货；而原供货查找仅限同区，会让远处农场库存瞬间进入车辆。这是可独立复现的真实运输缺陷，见下述隔离原型，不把区域池食品算作已送到可交易柜台。

结构产能仍不足。28 农场工人 +17 码头工人，14 日实际食品生产仅 **171.5711 份/日**；616 人按原饥饿下降 0.05/分钟和每份 +52 的理想需求约 **852.9231 份/日**。按实际平均能源、现有 45 人每人真实工作满 480 分钟估算上限也约 **482.5813 份/日**，还至少需要约 35 个完成同样时数的食品岗位。这个上限没有冒充实际出勤/已获批准招聘，也没有把工业材料自动变成食物。农场真实劳动 93,112.761 分钟、用于有空间生产的分钟 70,351.603；码头分别 44,987.852/42,987.246，真实工资和占用费仍支出。食品岗位没有增长，只有公共休班者 9 人流入已有零售/工业岗位。`farmOffers` 保留真实现金、受保护工资、500m 家到岗位路网与可接触申请人候选，但当前没有持久化的真实招聘公告/到场申请/双方接受流程。

财政平均净流失约 4,907.68/日。14 日公共工资实付 91,890.642、运维材料采购 32,293.1952、治安采购 7,080；主要真实收入为票款 24,176、工资税 13,609.1162、销售税 12,957.0653、经营费用 8,694.8731、采购税 3,170.1752、批发税 314.9271。资金承诺机制已在余额下降后缩减公共已授权来日时数；最终全职规划 137,760 分钟，实际来日可资助 56,539 分钟，服务缺口应继续公开。不得为收支绿灯默认加税、赠款或抹掉欠薪。
