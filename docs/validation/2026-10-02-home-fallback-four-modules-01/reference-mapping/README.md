## 关键适配与缺口

- REF-B01落地窗不适配本栋真实窗洞bottom0.8m/玻璃高1.4m。首批保原窗台和洞口改风格；全高洞口须新可信geometry/profile及碰撞/存档复验。54洞/53玻璃缺陷仍开放。
- REF-B03独立石柱无精确52物理ID；A04墙角、D03视觉梁、A23水平桥廊梁都不能当已支持石柱。REF-B12独立墙格栅只与A10窗棂族条件关联，墙装/通风孔尚未定义。
- REF-B09暖壁灯、REF-B15地面灯线和檐下/入口灯只可作F20/D05安装变体提案；不得复用原吊灯/床灯/背板pivot而直接称fit。REF-B04视觉梁不证明承力，桥廊板/栏/梁/支座/landing与route/access须同一新可信描述。
- REF-B11长槽是B03＋R16/植株组合，不能替代B01独立盆器＋B02盆株。盆底接支撑、树根接土面的接口严格分开。这两图没有独立盆景的精确展示。
