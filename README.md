# 云山巨城

浏览器中的中式未来体素山城：跨山的 11 片城区、612 栋建筑、瀑布与市政中枢天枢阁，持续运行的市民、交通、商业和治理系统。玩家从外星旅人开始，逐步学习、谋生、居住、经营、建立关系或参与治理。

完整需求、实际验证与未完成范围见 [开发备忘录.md](./开发备忘录.md) 和 [需求实现验证矩阵](./docs/需求实现验证矩阵.md)。原始 [提示词.md](./提示词.md) 保持不变。本工作区版本是持续开发中的可玩实现，完整社会制度、军事、外交等领域仍待深化。

## 启动

需要 Node.js 22.19 或更新版本，以及支持 WebGL 2 的浏览器。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，默认 `http://localhost:5173`。生产构建与本地预览：

```bash
npm run build
npm run preview
```

资源全部随项目打包；运行不需要账户、密钥或外部贴图。浏览器必须开启硬件加速。画质、渲距、帧率上限、动态分辨率与模拟精度在城市手册的设置页调整。

## 游览与生活

| 操作 | 按键或入口 |
| --- | --- |
| 步行 / 已登机无人机移动 | WASD 或方向键，Shift 加速 |
| 环顾 | 拖动鼠标；步行时双击画布可锁定鼠标，Esc 释放 |
| 寻找航空器 | 底部「找无人机」「去机场」标出真实停机位路线 |
| 无人机升降 | R / Q 或 Space / Ctrl；滚轮前后移动 |
| 已登机战机飞行 | R 垂直起飞；持续前进，拖动转向，滚轮调速，R / Q 升降 |
| 入口、人物、乘车、楼梯 | 靠近后 E；楼梯在室内左后方，天枢楼梯位于固定内核 |
| 驾驶车辆 | 取得司机权限并接近可驾驶载具；W 加速、S 减速、A / D 在路口选择转向、Space 制动 |
| 暂停、俯瞰 | F 暂停城市，T 回到全城镜头 |
| 放置 / 回收体素 | 在允许改造的近处按 B / X，单块 0.2 m，有材料消耗、碰撞与小台阶支撑 |
| 时间、速度、画质、存档 | 底部时钟及城市手册 |

在舆图选择目的地会标出真实交通路线。无人机在城市停机位现场租用，费用 24 云币；走近舱门后登机，身体随航空器实际移动。机场军用垂直起降战机需要累计卫士与驾驶员身份。飞行消耗电量并受天气与空域规则约束；请求返航、等待落地停稳后才能退出，随后继续步行生活。租约归还和补能也在停机位操作。进入建筑需接近南侧入口，使用设施和交谈需要真实位置与权限。

城市手册包括生活、城市、交通、人脉、产业和设置。寻找工作、学习考试、租房和休息；到市集消费或购买食材，按配方和火候烹饪，等待完成后食用。商人可以创办公司、扩张、雇人、上市、买卖股份或并购；科学家可以投入资金与时间研究七类技术。政策和调查结果经过模拟时间反馈，不会立刻兑现。

与共同居住的伴侣商议生育需要双方意愿、健康和真实扶养储备。孕期为 270 个游戏日，出生后登记新居民、照护与扶养，六岁开始学校教育，十八岁按实际毕业情况进入成年生活；调整一天内的时刻不会跳过孕期。死亡时按家庭关系处理已有现金与企业权益，银行资产及债务继承仍待完善。

在书院或山顶亭填写作品内容，支付费用并累计现场创作时间；离场会暂停，完成后到市集、亭子或公共议事厅发表，附近居民阅读并传播。公共见闻可以记录水质、治安与预算，有可核验的观察证据、误报更正和声望反馈。公共议事厅接受教育、医疗与交通诉求，登记后经过模拟日历与真实预算反馈。

天枢阁的市民大厅、公开议事空间和观景层开放。行政、数据、能源、应急、决策及地下档案/金库按楼层检查权限。获得的身份包可以叠加，改变显示职业不会清除已有权限。城市会持续消耗资源和产生事件；玩家也需要食物、休息和医疗。默认一真实秒推进一游戏分钟，一天约 24 分钟；加速会同步城市人物与交通。隐藏页面时暂停步进，目前没有离线推进。

## 存档

旅程在当前浏览器的 IndexedDB 中保存，每隔约 30 秒前台运行时间自动保存，也可手动保存。玩家、全局与 256 米地域分块分别存储，仅重写变更部分，并在一次事务中提交完整清单；保留上一完整代用于损坏恢复。存储受限时尝试本地存储原子整包回退，也可导出 JSON 文件跨浏览器保留。导入检查世界兼容性、实体引用、数值和计时器，坏档会保留正在运行的城市。目前读档仍组装完整状态、保存仍扫描全部分块，纯统计远区和按需读取尚待实现。

更新程序导致世界布局变化时，旧世界存档可能无法直接导入；先导出备份。请勿通过清理浏览器站点数据来迁移旅程。

## 验证

```bash
npm test
npm run build
npm run test:ui
npm run test:browser
npm run benchmark
npm run audit:economy
```

浏览器脚本会启动并关闭本地测试服务器，需要可用的 Chromium。默认路径 `/usr/bin/chromium`，可用 `YUNSHAN_CHROMIUM` 指定其他可执行文件。浏览器结果、日夜/室内截图和长期模拟数据写入 `artifacts/`。`?debug=1` 开启仅供本地检查的状态接口，普通启动不暴露这个接口。

规则测试覆盖时间顺序、需求与设施、资金/库存/股份、通勤和手控驾驶、政策与警务、关系、楼层权限、烹饪/科研/审计、生命/慈善及坏档原子拒绝。长期模拟以明确的 8× 加速检查 10,000 Tick、有限状态、存档恢复和完全一致续演；经济审计另记录实际税费、票款、工资、公共支出、居民生命与自主科研，验证公共收支。性能 benchmark 应单独运行，避免同时运行的测试争用 CPU。

本轮已接入实际出勤生产、雇主现金约束、真实采购收款方、家庭扶养和食材储备。长期财政及企业稳态、全城银行资产负债仍需按审计结果继续完善。动态出生人口与附近建筑/地形细部已有实现；当前远区市民仍保留个体分频状态，纯统计聚合、完整建筑编辑和模拟流式加载尚未完成。实际运行结果与后续入口见开发备忘录。

云端 Chromium 使用软件 GPU 做功能验收，Node 跑数只测模拟 CPU。真实 macOS Safari / Chrome / Firefox 的硬件帧率、内存和长时游玩尚未验证，不能由这些结果推断。
